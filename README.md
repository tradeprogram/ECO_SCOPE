# 에코스코프

**내륙습지 개방수면 원격판독 · 국립생태원 생태정보 플랫폼**

2026년 국립생태원 경영혁신 아이디어 공모전(AX 기반 업무효율화) 출품작 · 접수 마감 2026-09-13

---

## 사업 개요

전국 내륙습지조사는 **5년 1주기**로 시행됩니다. 특정 습지가 해당 주기 내 언제 조사되는지는
보장되지 않으며, 조사와 조사 사이 기간에 습지에서 발생한 변화는 기록으로 남지 않습니다.

Sentinel-1 위성은 동일 습지를 **12일 간격**으로 관측합니다. 구름을 투과하는 레이더이므로
장마철과 태풍기에도 관측이 중단되지 않습니다. 본 시스템은 그 관측 자료를 습지별 시계열로
변환합니다.

```
습지 경계 (국립생태원 내륙습지 공간자료)
   ↓
관측 가능성 판정   궤도별 연간 관측 횟수 → 전 기간 연속 관측되는 relative orbit 하나로 고정
   ↓
개방수면 판독      Sentinel-1 VV < −16 dB, 경사 5도 초과 지형 제외
   ↓
원인 분리          개방수면 감소의 원인이 수량 감소인지 식생 피복인지 구분
                   VV 평균 상승 + Sentinel-2 NDVI 상승 → 식생피복으로 판정
   ↓
품질 관리          개방수면이 없는 습지는 지표 비적용, 임계값에 변동하는 판독은 저신뢰 표시
```

## 판독 실적

| 항목 | 실적 |
|---|---|
| 판독 습지 | 101개소 |
| 판독 기간 | 2018~2025년 (8개년) |
| SAR 관측 처리 | 4,894회 |
| 평균 재방문 주기 | 12.7일 |
| 개방수면 지표 성립 | 24개소 |
| 식생피복 관측 습지 | 18개소 |
| 광학 교차검증 습지-연도 | 64건 |

## 실측 결과

우포늪(면적 196 ha) 2024년, orbit 127 고정, 관측 30회 기준입니다.

| 시기 | 개방수면적 | VV 평균 | Sentinel-2 NDVI |
|---|---|---|---|
| 4월 12일 | **100.1 ha** | −22.3 dB | 0.09 (4/28) |
| 8월 10일 | **1.0 ha** | −8.8 dB | 0.68 (8/11) |
| 11월 26일 | **59.9 ha** | −18.9 dB | 0.06 (11/24) |

8월에 개방수면이 100 ha 에서 1 ha 로 감소합니다. **수량이 감소한 것이 아닙니다.**
수량이 감소하였다면 후방산란도 함께 낮아져야 하나, 반대로 13 dB 상승하였습니다.
동일 시기 광학 NDVI 는 0.09 에서 0.68 로 상승하였습니다. 수생식물이 수면을 덮은 것입니다.

SAR 와 광학이 서로 독립적으로 동일한 결과를 제시합니다. 이 계절 신호는
**습지 육상화·천이 모니터링**이 필요로 하는 지표에 해당합니다.

## 관측 가능성을 판독보다 먼저 확인하는 이유

우포늪을 관측하는 relative orbit 별 연간 관측 횟수입니다.

| orbit | 2018 | 2019 | 2020 | 2021 | 2022 | 2023 | 2024 | 2025 |
|---|---|---|---|---|---|---|---|---|
| **127** | 21 | 30 | 32 | 29 | 29 | 30 | 30 | 34 |
| 54 | 16 | 32 | 31 | 30 | 28 | 30 | 25 | 31 |
| 61 | 31 | 29 | 32 | 28 | **1** | **1** | **0** | 11 |
| 134 | 29 | 32 | 31 | 29 | **0** | **1** | **0** | 8 |

orbit 61 및 134 는 2021년까지 연 30회 내외로 관측되다가 2022~2024년 관측이 중단됩니다.
**Sentinel-1B 가 2021년 12월 고장으로 소실된 궤도입니다.** 2025년 관측이 회복된 것은
2024년 12월 발사된 Sentinel-1C 가 동일 궤도면을 승계하였기 때문입니다.

이를 확인하지 않고 궤도를 선정하면 3개년 판독이 전부 결측됩니다.
본 저장소의 최초 실행에서 실제로 해당 오류가 발생하였습니다. 분석 구간의 첫 해(2018년)를
기준으로 궤도를 선정한 결과 orbit 61 이 채택되었고 2022~2024년 판독이 0건이 되었습니다.
해당 산출물은 `data/interim/deep_orbit_from_first_year.jsonl` 에 기록으로 보존하였습니다.

**관측이 이루어지지 않은 기간을 '변화 없음'으로 해석하지 않는 것**이 본 시스템의 설계 원칙입니다.

## 본 시스템이 수행하지 않는 사항

**수위는 측정하지 않습니다.** SAR 는 수면의 면적을 관측하며 수심은 관측하지 않습니다.
개방수면적이 감소하였다는 사실만으로 수위가 저하되었다고 판단할 수 없습니다.

**식생 하부 침수는 판정하지 않습니다.** 이중반사 신호는 논의 담수·중간낙수 관리 주기와
동일한 대역에서 변동합니다. 선행 과업(충청남도 농경지)에서 사건 발생 17일 *이전* 영상이
사건 이후 영상보다 큰 이상치를 산출한 사례가 확인되었습니다.
근거가 확립되기 전까지 본 판정은 화면에 표출하지 않습니다.

**개방수면이 없는 습지에는 개방수면 지표를 적용하지 않습니다.** 연중 최대 개방수면율이
5% 미만인 습지는 삼림습지·초본습지와 같이 SAR 로 관측할 수면이 존재하지 않는 유형입니다.
기준선이 0에 가까운 상태에서 비율로 피복을 판정하면 의미 없는 수치가 산출됩니다.
본 판독에서 101개소 중 77개소가 이에 해당하며 **지표 비적용**으로 별도 집계하였습니다.

**저신뢰 판독을 평균에 포함시키지 않습니다.** 고정임계와 Otsu 판독의 차이가
최대 개방수면적의 20%를 초과하는 습지-연도는 화면에 저신뢰로 표시하여 그대로 제시합니다.

## 정본 반영이 필요한 사항

**습지 경계.** 현재는 OpenStreetMap 폴리곤으로 운영됩니다(© OpenStreetMap contributors, ODbL).
정본은 공공데이터포털의 `국립생태원_내륙습지 공간데이터 및 속성정보`
(내륙습지 **2,704개소**, SHP, EPSG:5186)이며, 내려받기에 로그인이 필요하여 아직 반영하지 못하였습니다.

OSM 기반 경계의 한계는 실측으로 확인되었습니다. 면적 상위 폴리곤이 간척지 등 이질 지형이어서
판독창이 수면과 육지의 이봉 분포를 형성하지 못하였고, 우포늪은 유형 태그조차 부여되어 있지 않습니다.
정본 자료를 `data/raw/nie_inland_wetlands/` 에 배치한 후 다시 생성하면 습지명·유형·코드가
그대로 반영되며 모든 수치가 정본 경계 기준으로 재산출됩니다. 코드 변경은 필요하지 않습니다.

**식생피복 판정 임계.** VV −13 dB 는 시범 습지 1개소(우포늪 2024년)에서 도출한 잠정값입니다.
해당 습지에서 개방수면 관측은 −16~−22 dB, 식생피복 관측은 −8.8~−12 dB 로 구분되었고
그 사이 구간은 관측되지 않았습니다. 전국·습지유형별 보정 완료 전까지 확정값이 아닙니다.

## 저장소 구성

```
src/nie/rs/          GEE 헬퍼, Sentinel-1 개방수면 판독, Sentinel-2 교차검증, 배치 실행
src/nie/wetlands/    습지 레지스트리(정본 SHP / OSM 임시), 지표 집계
src/nie/ecobank/     국립생태원 생태자연도 오픈API 어댑터 (인증키 등록 시 연동)
scripts/             수집·판독·화면자료 생성
web/                 화면. 사전 생성 파일만 읽으며, 질의응답만 서버를 사용
api/                 에코스코프.agent 질의응답 서버리스 함수 (Vercel)
docs/                방법·자료·한계 문서 및 제출물
```

## 실행 방법

```bash
pip install -r requirements.txt
cp .env.example .env        # EE_PROJECT 를 기입합니다
earthengine authenticate
```

```bash
python scripts/fetch_wetlands_osm.py                                        # 습지 경계 임시 수집
python scripts/run_water_batch.py --top 100 --min-area 3 --years 2025 --out breadth.jsonl
python scripts/run_water_batch.py --wids "<습지 wid 목록>" --years 2018-2025 --optical --out deep.jsonl
python scripts/build_web_data.py breadth.jsonl deep.jsonl pilot.jsonl       # 화면용 자료 생성
python -m http.server 5178 --directory web                                  # 화면 확인
```

배치는 중간에 중단되더라도 동일한 `--out` 으로 다시 실행하면 이어서 처리합니다.
GEE 계정이 제한 모드인 상황을 정상 조건으로 가정하여 설계하였습니다.

## 수치의 산출 경로

화면에 표시되는 모든 수치는 `src/nie/wetlands/aggregate.py` 한 곳에서 산출됩니다.
화면은 계산을 수행하지 않습니다. 동일한 수치가 두 곳에서 다르게 계산되는 것을 방지하기 위한 구성입니다.
