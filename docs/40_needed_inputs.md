## 1. 에코뱅크 오픈API — 발급 완료, 동작 확인

- **발급 레이어 10종** (습지_내륙_면, 습지_생물상_조사_점, 생태계정밀조사 조사지역_면·식생_면·
  양서파충류_점·저서무척추동물_점·조류_점, 자연환경조사 식생_면·양서파충류_점·조류_점)
- 인증키는 `.env` 의 `ECOBANK_API_KEY` (저장소에 넣지 않습니다)
- 어댑터: `src/nie/ecobank/client.py`

**확인된 것**

- `습지_내륙_면` 속성조회 `totalCount = 2,704` — 공공데이터포털 공개 데이터셋과 일치합니다.
- 스키마에 습지명(`wtlNm`)·습지코드(`wtlCodeId`)·유형명(`wtlTyNm`, 예: 산지습지)·
  보호지역 지정명(`wtlPrtcAreaAppnNm`)·주소(`addresNm`)·중심좌표가 모두 있습니다.
- WFS 는 `outputFormat=application/json` 으로 GeoJSON(EPSG:5186) 응답을 줍니다.

**막혀 있는 것**

- **엔드포인트 처리 시간 상한이 약 10초입니다.** 실패는 전부 10.2초 부근에서 HTTP 500 으로
  떨어지며, 부하에 따라 같은 요청이 성공하기도 실패하기도 합니다.
- 전량 수집은 `scripts/fetch_wetlands_ecobank.py` 로 5건씩 나누어 받고 있습니다.
  진행분은 `data/raw/wetlands_ecobank_pages.jsonl` 에 즉시 기록되므로 끊겨도 이어받습니다.
- WMS 는 아직 성공한 적이 없습니다(작업 시점 60~84초 후 HTTP 500).
  속성조회는 같은 키로 동작하므로 키 문제는 아닙니다.

**권장** 요청이 몰리지 않는 시간대에 `scripts/fetch_wetlands_ecobank.py` 를 다시 실행하십시오.
`scripts/probe_ecobank.py` 로 레이어별 응답 상태를 먼저 확인할 수 있습니다.

## 2. 생태자연도 오픈API (공공데이터포털) — 발급 완료, 부분 확인

- 서비스: `국립생태원_생태자연도 서비스` (`B553084/ecoapi/EcologyzmpService`), 각 오퍼레이션 일 10,000회
- 인증키는 `.env` 의 `DATA_GO_KR_KEY`
- 어댑터: `src/nie/ecomap/client.py`

**확인된 것**

- **WFS 만 동작합니다.** `outputFormat=application/json` 으로 GeoJSON(EPSG:5186) 을 줍니다.
  (우포늪 일대 20피처 = 302 KB, 11초)
- 응답 스키마에 본 과업과 직결되는 필드가 있습니다.

  | 필드 | 뜻 |
  |---|---|
  | `eczm_grad` | 생태자연도 등급 |
  | `smld_evl_grad` | 습지 평가등급 |
  | `precise_smld_ttle` | 정밀 습지 명칭 |
  | `vtn_evl_grad` / `plnt_cln_ttle` | 식생 평가등급 / 식물 군락 명칭 |
  | `tpgrph_evl_grad` / `tpgrph_ttle` | 지형 평가등급 / 지형 명칭 |

**막혀 있는 것**

- **WMS 와 속성조회는 게이트웨이 오류(HTTP_ERROR, reasonCode 04)로 실패합니다.**
  15~29초 만에 떨어지며, 같은 키로 WFS 는 1.3초에 오므로 키 문제가 아니라 해당 백엔드 문제입니다.
- 습지별 등급 집계(`scripts/fetch_ecomap_grades.py`)를 30개소 대상으로 돌렸으나
  **8개소에서 멈췄고 결과도 아직 신뢰할 수 없습니다.**
  - 등급 코드 `9` 가 나옵니다. 문서에 없는 값이라 무엇인지 확인해야 합니다.
  - 여러 습지에서 피복률이 0.0 으로 나옵니다. 해당 습지가 간척지·수면이라 생태자연도
    적용 대상이 아닐 가능성이 있으나 **검증하지 못했습니다.** API 가 응답하지 않아
    원인 진단을 중단했습니다.
- 이 자료는 검증 전까지 화면에 올리지 않았습니다.

## 5. 아직 1차 출처를 확인하지 못한 사실

제안서에 쓰기 전에 근거를 확정해야 합니다. 현재 화면에는 **5년 1주기**로 적고 있습니다.

- 전국 내륙습지조사의 실제 주기와 연간 조사 개소 수
- 내륙습지 현장조사 1개소당 투입 인력·일수·비용

두 번째가 없으면 비용 절감률은 쓰지 않는 편이 안전합니다. 근거 없는 절감률은 심사에서 역효과입니다.
현재 화면은 **관측 빈도**로만 주장하고 있습니다.
