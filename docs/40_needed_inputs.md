# 받아야 하는 것

지금 막혀 있거나, 있으면 결과가 확실히 좋아지는 입력만 적는다.
없어도 시스템은 돌아가지만, 있으면 제출물의 근거가 달라지는 것들이다.

## 1. 국립생태원 내륙습지 공간자료 (SHP) — **가장 중요**

- **무엇** `국립생태원_내륙습지 공간데이터 및 속성정보` (내륙습지 2,704개소)
- **어디** 공공데이터포털 https://www.data.go.kr/data/15086410/fileData.do
- **형식** SHP · EPSG:5186 (Korea 2000 / Central Belt 2010) · UTF-8
- **제약** 다운로드에 data.go.kr 로그인이 필요하다. 자동 수집 불가.
- **넣을 곳** 압축을 풀어 `data/raw/nie_inland_wetlands/` 에 `.shp/.shx/.dbf/.prj` 통째로

이걸 넣으면 달라지는 것:

- 지금의 OSM 부트스트랩(내륙 989건, 이름 있는 것 71건)이 정본 2,704개소로 교체된다
- 습지명·습지코드·습지유형·람사르 지정 여부가 화면에 그대로 들어온다
- 간척지 같은 이질 폴리곤이 사라져 저신뢰 판독이 크게 줄어든다
- 제안서에 "전국 내륙습지 2,704개소" 라는 정본 모집단을 쓸 수 있다

넣은 뒤 재생성:

```bash
python scripts/run_water_batch.py --top 60 --years 2021-2025 --out nie.jsonl
python scripts/build_web_data.py nie.jsonl deep.jsonl pilot.jsonl
```

코드 변경은 필요 없다. `registry.load()` 가 정본을 먼저 잡는다.

## 2. 공공데이터포털 인증키 (생태자연도 오픈API)

- **무엇** `국립생태원_생태자연도 서비스` 활용신청
- **어디** https://www.data.go.kr/data/15057288/openapi.do
- **승인** 자동승인. 개발계정 일 10,000회.
- **넣을 곳** `.env` 의 `DATA_GO_KR_KEY=`

어댑터는 `src/nie/ecobank/client.py` 에 이미 있다(WMS / WFS / 속성조회).
키가 없으면 `available() == False` 를 돌려주고 화면은 해당 레이어만 감춘 채 동작한다.

이걸 넣으면 달라지는 것: 습지 판독 결과 위에 **생태자연도 등급**을 겹쳐
"개방수면이 줄고 있는 습지가 생태자연도 몇 등급 지역인가" 를 화면에서 바로 답할 수 있다.
공모 심사의 '전략연계성' 항목에 직접 걸린다.

> 키는 서버에만 둔다. WMS URL 에 ServiceKey 가 그대로 들어가므로 브라우저에 직접 물리면 새어나간다.

## 4. Google Earth Engine 컴퓨트 쿼터

현재 계정(`gen-lang-client-0419682396`)이 **noncommercial 제한 모드**다.
경고가 매 호출마다 뜨고 대면적 연산은 실패한다.

습지는 AOI 가 작아 지금 수준(습지 1개소·1개년 ≈ 40초)에서는 감당된다.
다만 정본 2,704개소를 다년으로 돌리려면 부족하다. 선택지:

- 다른 GEE 프로젝트로 전환 (`.env` 의 `EE_PROJECT` 만 바꾸면 된다)
- 또는 대상을 습지보호지역·람사르습지 등으로 좁혀서 제출 (권장 — 심사에는 이게 더 낫다)

## 5. 확인이 필요한 사실 두 가지

제안서에 쓰기 전에 근거를 확정해야 한다. 지금은 **확인 불가**로 두고 있다.

- **전국 내륙습지조사의 실제 주기와 연간 조사 개소 수.**
  전략 문서는 5년 주기로 적고 있으나 1차 출처를 확인하지 못했다.
  "5년에 1회" 는 이 제출물의 핵심 대비 수치이므로 국립생태원 공식 자료로 못박아야 한다.

- **내륙습지 현장조사 1개소당 투입 인력·일수·비용.**
  효율 개선 수치를 정량으로 쓰려면 필요하다. 없으면 "관측 빈도" 로만 주장하고
  비용 절감률은 쓰지 않는 편이 안전하다 — 근거 없는 절감률은 심사에서 역효과다.
